これまでの作品と題材を重ねない：タワマン孤島（停電のタワマン）、ホワイト案件（闇バイト）、#拡散希望（ネット炎上・冤罪）、二人の息子（AIの声のなりすまし・実家）。

## 数字から決めたこと（moshimo-analytics の notes/itsuwa-insights.md、analysis/itsuwa-2026-11-02.md・11-04.md）

## 案1　置き配（おきはい）
**ひとことで言うと**：毎朝、玄関の前に、頼んでいない段ボールが1つ届く。中に入っているのは、昨夜の自分の寝顔の写真。

**なぜ見られるか**
- 置き配・玄関前の段ボールは、ほとんどの人が毎週見ている光景。「うちの前にも届いたら」と思わせる身近さ（#拡散希望が闇バイトより見られた傾向）。
- 作品の顔は「玄関前の段ボール」1つ。どの話も「箱を開ける」瞬間から入れるので、途中の話から見た人も2秒で分かる（途中の話の再生が多い傾向）。
- 「送り主はだれ？」で毎話コメントが割れる。

**登場人物**
- 相沢ミオ（27）：語り手。駅から遠い3階建てアパートの2階でひとり暮らし。在宅で働くデザイナー。几帳面で、鍵を2回確かめる。声＝落ち着いた若い女性。
- 戸川（50代）：アパートの管理会社の担当。親切だが、合鍵を持っている。声＝低く丁寧な男性。
- 隣の部屋の男・ナガセ（30代）：夜勤で昼に帰ってくる。ミオとはあいさつだけの仲。声＝ぼそぼそ話す男性。
- 前の住人・水野サキ（当時26）：ミオの前にこの部屋に住んでいた。1年前に引っ越したことになっている。声＝第4話から電話の声だけ。
- 配達員・ケン（20代）：毎朝ミオのアパートを回る。声＝明るい若い男性。

**全5話の流れ**
1. **第1話 届いた**：毎朝届く箱。3日目の写真は昨夜の寝顔。部屋の中にカメラはない。引き：今朝の箱の伝票の届け先は「水野サキ様」。この部屋の前の住人の名前。
2. **第2話 合鍵**：管理会社の戸川が「合鍵は金庫にある」と見せるが、1本足りない。隣のナガセが箱を置く姿が防犯カメラに。引き：ナガセの部屋の郵便受けにも、ミオ宛ての箱が届いていた。
3. **第3話 前の住人**：サキは引っ越していない。退去の手続きをしたのは戸川ひとり。写真の撮り方が「1年前のサキの部屋」と同じ角度だと気づく。引き：天井の点検口の奥から、スマホの充電の小さな光。
4. **第4話 送り主**：点検口の奥のスマホは、サキのもの。箱を送っていたのは、ミオを脅す誰かではなかった。サキからの電話「その部屋から、今すぐ出て」。引き：玄関の外に、戸川が合鍵を持って立っている。
5. **最終話 置き配**：写真はミオを脅すためではなく、「この部屋で何が起きているか」をミオに気づかせるため、サキと配達員ケンが送っていた。戸川がサキの部屋で1年前にしたことの記録がそろう。終わり：引っ越したミオの新しい部屋の前に、また段ボールが1つ。伝票の字は、見覚えのない字。

**第1話の冒頭30秒の絵**
- 0秒：朝の玄関の外。ドアの前に段ボール1つ。ミオの心の声「頼んでいない荷物が、また届いた」。
- 3秒：玄関の内側。カッターで開ける手のアップ。中から写真が1枚。
- 6秒：写真の寄り。暗い部屋で眠るミオの顔。右下に昨日の日付と「3:12」。
- 10秒：ミオの顔のアップ（字幕より上）。「昨夜、この部屋には、私しかいなかった」。
- 15〜30秒：部屋を見回す引きの絵。窓・クローゼット・ベッドの上の天井。どこにもカメラがない。天井の点検口だけが、少しずれている（最後まで気づかせない置き方）。タイトル。

**映像のテイスト**
- 色：朝の白っぽい外光と、夜の青い部屋。差し色は段ボールの茶色と伝票の赤。
- 人物：noir.js の顔のアップ（close）と全身（figure）。ミオの顔は字幕（y=1262）より上。
- 演出：段ボール・写真・伝票の寄り、防犯カメラの白黒の映像、天井の点検口。写真は「昨夜の何時何分」を必ず入れて、毎話の数字が一本の時刻表になる。

**既存の部品で作れるか**
- そのまま使える：kakusets の akariRoom・frontDoor・aptExterior・misakiRoom（ひとり暮らしの部屋・アパートの外・玄関）、noirsets の genkan・doorInside、noirsets2 の lockTurn（鍵）、futarisets の photo（写真）・lockApp、doorCam（防犯カメラの映像の枠に流用）。
- 足すもの：段ボールと伝票（drama/engine に1つ）、天井と点検口、管理会社の鍵の金庫（noirsets2 の safeDial を元に）。どれも2D図形で半日ほど。

## 案2　ドラレコ
**ひとことで言うと**：深夜のタクシー。後部座席の客が「この車のドラレコに、さっきの事故が映っている」と言う。運転手は、そんな事故を知らない。

**なぜ見られるか**
- 終電のあとのタクシー、ドラレコ（ドライブレコーダー）は身近な道具。密室・2人・一晩という形は、二人の息子で入りが作りやすかった「1つの場所で時計が進む」形をそのまま生かせる。
- 作品の顔は「ドラレコの画面（時刻つき）」と「メーターの金額」。金額と時刻が話ごとに上がっていくので、途中から見ても今どこかが2秒で分かる。
- 語り手の運転手が「何かを隠している」ことが最後に分かる仕掛けで、「どっちが悪い？」とコメントが割れやすい。

**登場人物**
- 小野寺ショウジ（48）：語り手。個人タクシーの運転手。娘の学費のために夜だけ走る。心の声はウソを言わないが、言わないことがある。声＝落ち着いた中年の男性。
- 後部座席の女・ユキ（30代）：行き先を言わず「とりあえず、まっすぐ」。ショウジの名前を知っている。声＝静かな女性。
- 小野寺マユ（19）：ショウジの娘。今夜、電話がつながらない。声＝電話越しの若い女性。
- 配車センターの男・久保（50代）：無線で話す。声＝事務的な男性。
- 黒いワゴンの男：第3話から、ずっと後ろを走る車。顔は最終話まで見せない。

**全5話の流れ**
1. **第1話 乗車**：0時41分、ユキが乗る。「この車のドラレコに、10分前の事故が映ってる」。映像を戻すと、ショウジの車が自転車をはねる映像。でもショウジに覚えはない。引き：映像の最後、後部座席に、もう乗っているユキの顔。
2. **第2話 10分前**：映像の時刻は、ユキが乗る前。ユキはその前からこの車にいた？ 配車センターの記録では、この車は0時30分から「回送」。引き：ユキ「娘さん、今どこにいるか知ってる？」
3. **第3話 回送**：マユに電話がつながらない。後ろに黒いワゴン。ドラレコの映像は誰かに書き換えられている。引き：ユキがスマホを見せる。マユが黒いワゴンの後部座席で眠っている写真。
4. **第4話 迂回**：ユキは犯人ではなく、1年前の同じ交差点の事故で弟を亡くした姉だった。あの夜の映像を消したのは、ショウジ自身。引き：ショウジが自分のドラレコのカードを抜き、窓の外に捨てる。
5. **最終話 ドラレコ**：消した映像の本当の中身＝あの夜、ショウジは事故を見ていた。はねたのは黒いワゴン。ショウジは口止めの金を受け取り、そのお金が娘の学費になっていた。マユを連れ去ったのも黒いワゴンの男たち。ショウジは捨てたはずのカードの「もう1枚」をユキに渡す。終わり：ユキのタクシーを降りたあと、次の客が乗る。「この車のドラレコ、見せてもらえますか」。

**第1話の冒頭30秒の絵**
- 0秒：ドラレコの画面いっぱいに、夜の交差点。右上に「00:31」。自転車のライトがこちらに向かってくる。
- 2秒：急ブレーキの音、画面が揺れて黒くなる。字幕「この映像に映っているのは、あなたの車です」。
- 5秒：タクシーの車内、ルームミラーに映る後部座席の女の目（ユキ）。
- 9秒：ショウジの横顔のアップ（字幕より上）。心の声「そんな事故、俺は知らない」。
- 15〜30秒：メーター「4,820円」、ナビの時刻「00:44」、フロントガラスの外の誰もいない国道。ユキ「じゃあ、見せて。そのドラレコ」。タイトル。

**映像のテイスト**
- 色：夜の国道のナトリウム灯のオレンジと、ドラレコ画面の青白さ。差し色はメーターの赤い数字。
- 人物：運転席の横顔とルームミラーの中の目の2つを主に。顔は字幕より上（ミラーは画面の上3分の1）。
- 演出：ドラレコの画面（時刻・速度・ノイズ）を作品の顔に。1場面1つ：ミラー→メーター→画面。車外は流れる街灯だけで、移動は少ない絵で見せる。

**既存の部品で作れるか**
- そのまま使える：kakusets2 の carInside・nightDrive・carBack・garage、noirsets の carFront・carWindow、noirsets2 の parkingLot（パトカー・夜明け）・runStreet、kakusets2 の recScreen（録画の画面）。
- 足すもの：タクシーの運転席（ハンドル・メーター・ルームミラー）、ドラレコの画面（時刻と速度の文字・巻き戻し）、黒いワゴン。carInside を元に1日ほど。

## 案3　父のスマホ
**ひとことで言うと**：亡くなった父のスマホに、毎朝7時「おはよう、あなた」と知らない女からメッセージが届く。父には、もうひとつの家があった。

**なぜ見られるか**
- 親のスマホ・遺品整理は、30〜60代の誰もがいつか向き合うこと。「父に知らない家族がいたら」は、怖さと気まずさが同時に来る題材（わかる・不思議・不安を同時に）。
- 作品の顔は「父のロック画面に届く通知」。毎話の1フレーム目を通知の一文にでき、途中の話から見ても2秒で分かる。
- 「母に言う？ 言わない？」「女はだれ？」で、見る人の意見が割れる。

**登場人物**
- 井上ナツキ（34）：語り手。父の遺品整理のために、ひとりで実家の団地に戻る。会社員。冷静だが、父とは5年口をきいていなかった。声＝はっきりした女性。
- 井上の母・タエコ（63）：父の死後、施設に入った。父のことを何も話さない。声＝穏やかな年配の女性。
- 「おはよう、あなた」の女・カズミ（50代）：父のスマホにだけ連絡してくる。声＝第2話から電話の声。
- カズミの息子・リョウ（17）：父を「お父さん」と呼ぶ高校生。声＝若い男性。
- 父・井上タツオ（享年66）：録音と動画の中だけに出てくる。声＝ボイスメモの穏やかな男性。

**全5話の流れ**
1. **第1話 通知**：父の葬儀の翌朝7時、父のスマホに「おはよう、あなた」。ロックは父の誕生日で開く。カズミとの5年分のメッセージ。引き：写真フォルダに、ナツキの知らない男の子と父が、ナツキの家族写真と同じ構図で写っている。
2. **第2話 もうひとつの家**：カズミの家は、実家の団地の向かいの棟。父は毎晩、窓から窓へ手を振っていた。父のスマホに電話をかけると、出たのはリョウ「お父さんの携帯、どうして持ってるの？」。引き：ナツキのスマホに、母から「その子に会わないで」。
3. **第3話 向かいの窓**：母は全部知っていた。リョウはナツキの弟ではない。父の口座から毎月カズミへ送金。引き：カズミの部屋の窓に、葬儀のあと消えた父の位牌が置かれている。
4. **第4話 送金**：送金はカズミへの手当てではなく、20年前に父が起こした事故の償いだった。リョウの本当の父は、その事故で亡くなっていた。引き：父の最後のボイスメモ「ナツキには、言わないでくれ」。その声の後ろで、母の声がする。
5. **最終話 おはよう**：事故の夜、車を運転していたのは父ではなく母。父は20年、母の身代わりに償い続けていた。カズミが毎朝「おはよう、あなた」と送っていたのは、父が「家族にはもう言葉をかけてもらえないから」と頼んだ約束だった。ナツキは父のスマホから、はじめてカズミに返事を書く。終わり：翌朝7時、ナツキのスマホに知らない番号から「おはよう、ナツキ」。

**第1話の冒頭30秒の絵**
- 0秒：暗い団地の部屋、仏壇の前に置いた父のスマホのロック画面が光る。「7:00　カズミ　おはよう、あなた」。
- 3秒：ナツキの顔のアップ（字幕より上）。心の声「父が死んで、まだ2日」。
- 7秒：ロック画面の寄り。続けて「今日は寒いから、ちゃんと上着を着てね」。
- 12秒：パスコードの画面。父の誕生日を入れる指。開く。
- 18〜30秒：メッセージの一覧。5年前から毎朝7時、一日も欠かさず「おはよう、あなた」。いちばん新しい父の返事は、亡くなる前の夜「明日も、窓を開けておく」。タイトル。

**映像のテイスト**
- 色：昭和の団地の黄みがかった蛍光灯と、冬の朝の青。差し色はスマホの通知の白と、送金の数字の黄色。
- 人物：ナツキの顔のアップと、向かいの棟の窓の人影。父はスマホの写真・動画の中だけ。
- 演出：ロック画面の通知、メッセージ一覧、通帳の送金の列、向かいの窓。1場面に画面1つ。毎話の最初は必ず7時の通知から。

**既存の部品で作れるか**
- そのまま使える：noirsets2 の lockScreen（ロック画面の通知）、futarisets の photo（写真）・callLog（履歴）・butsuma（仏壇）・aiApp の型（アプリの画面）、noirsets の living・altar、kakusets2 の chatScreen（メッセージ一覧）。
- 足すもの：団地の部屋（狭い和室・ベランダ・向かいの棟の窓）、通帳の画面、窓越しの人影。futarisets の chanoma を元に半日ほど。
