# ドラレコ（dorareco・番号 7011〜7052）

深夜0時41分。タクシーのドラレコの車内カメラに、乗せていないはずの女が映っている。
女は後ろの席の足もとに伏せていた。1年前の今夜、0時41分にこのタクシーに乗った妹が、その夜から帰ってこない。
運転手のショウジは「覚えていない」と嘘をつく。ドラレコに残っていたのは、ショウジが誰にも言えなかった、1年前の金曜の夜。

drama/PROPOSALS-2026-11.md の 案2 をもとにした作品（置き配・父のスマホ に続く3本目）。
父のスマホ（ひき逃げ・交差点・償いの送金）と重ならないよう、案2 の「1年前の交差点の事故・口止めの金」はやめて、
**ドラレコの車内カメラの映像を売っていた運転手** と **それを買っていた男** の話にした。

## 本当のこと（最終話まで視聴者にも伏せる）
- **小野寺ショウジ（48）** は、みなと台交通（架空のタクシー会社）6号車の運転手。夜だけ走る。離婚して、大学2年の娘マユの学費をひとりで払っている。2年前、学費の借金で首が回らなくなった。
- そのとき「浮気調査の探偵」を名乗る **灰原（はいばら・40代）** から声がかかった。車内カメラの映像を **1本3万円** で買う、と。客がどこで乗り、どこで降り、電話で何を話したか。ショウジは何十本も売った。
- 灰原に「会社のドラレコの映像を、ネットでいつでも見られる道」を作ったのは、配車センターの **久保（50代）**。会社の無線もこっそり使える。第1話の無線の声は久保。
- **白石ハルナ（26）** は、毎週金曜0時41分に同じ店（駅前の花屋の閉店後）の前からショウジのタクシーに乗る常連だった。灰原は昔の客で、ハルナをつけまわしていた。灰原は「この女の金曜の映像を」とショウジに頼み、ショウジは売った。
- 1年前の金曜の夜、灰原から電話があり、ショウジは言われたとおり、ハルナをいつもの家の前ではなく **ひとつ手前の角** で降ろした。角には黒いワゴンが止まっていた。
- ハルナは、ワゴンから **逃げ切った**。そのまま誰にも知らせずに身を隠した（灰原にも、会社の誰かにも見つからないように）。家族の前からも消えたので「その夜から帰ってこない」は本当。姉の **ユキ（31）** だけが、半年後にハルナと連絡がつき、二人で今夜を計画した。
- ショウジは、あの夜の自分の映像だけは売らず、会社の機械から抜いた **SDカード** をサンバイザーの裏に1年隠していた（捨てられなかった）。ユキはそれを「妹から聞いて」知っている。
- 今夜（1年目の金曜、0時41分）、ユキはコンビニで止まった6号車に忍びこんで、後ろの席の足もとに伏せた。目的は、ショウジにカードを出させ、灰原と久保を引きずり出すこと。
- 灰原は会社の車内カメラで6号車の中を見ている。今度はマユに近づいている。

## 映像のテイスト
- 色：深夜の国道のナトリウム灯のオレンジと、ドラレコの画面の青白さ。差し色は **車内カメラの赤い REC の点**（作品の差し色は赤 D.rec）と、メーターの緑の数字。
- 人物：noir.js の顔のアップ（close）。運転席の横顔と、**ルームミラーの中の目** を主に。顔は字幕（y=1262）より上。ミラーは画面の上3分の1。
- 作品の顔：**ドラレコの車内カメラの画面**（魚眼で後ろの席を映す、白黒っぽい映像、左上に REC・右上に日付と時刻）。各話の頭の近くに必ず出す。時刻が話ごとに進む（0:41 → 0:52 → 1:20 → 1:50 → 朝）。どの話から見ても2秒で「タクシーの車内カメラに、何かが映っている」と分かる。
- 場面：運転席（ハンドル・メーター・無線機・ドラレコのモニター・ルームミラー）、後ろの席、フロントガラスの外の夜の国道、コンビニの駐車場、黒いワゴン。スマホの画面は写真・LINE・メッセージ・着信。1場面20〜30秒で1つのことだけ。
- 部品：drama/engine/dorasets.js（車内カメラの画面・運転席・後ろの席・ルームミラー・夜の国道・コンビニ・黒いワゴン・無線機・メーター）。スマホの画面は chichisets の msgList・lock を使う。写真は futarisets の photo。

## 全5話の構成
### 第1話 後部座席（0時41分）
- 出来事：深夜0時41分、回送で走る6号車。ドラレコの車内カメラの画面に、乗せていない女が映る。振り返っても後ろの席はからっぽ。女は足もとに伏せていた（10分前のコンビニで、鍵をかけずに降りた）。女は「止まらないで」と言い、ショウジの名前と娘の名前を知っている。1年前の今夜0時41分、この車に乗った妹のハルナが、その夜から帰ってこない。ショウジは「覚えてない」と答えるが、心の声は「嘘だった」。毎週金曜0時41分の常連だった。「会社はドラレコの映像を消した。でも、あなたは消していない」。そこへ無線「6号車、後ろのお客さん、そのまま乗せといて」。メーターは回送で、会社は客がいることを知らないはず。
- どんでん返し：①乗せていない女は、後ろの席の足もとに伏せていた ②1年前の今夜、この車に乗った妹が帰ってこない。ショウジは覚えていないと嘘をついた ③回送なのに、無線が後ろの客のことを言う。この車の中は、どこかで見られている
- 引き：ミラーの奥に黒いワゴン。ショウジのスマホに「久しぶりだな、小野寺さん。後ろの女、どこで降ろす？」。1年前と同じ番号。

### 第2話 回送（0時52分）
- 出来事：ショウジは返事をせず、回送のまま走る。会社の夜の当番に電話すると「今夜、6号車に無線は入れてない」。ユキが見せるハルナの1年前のLINE「今日の運転手さん、いつもと違う角で降ろすって」。マユに電話すると「今日、お父さんの会社の人って人が大学に来た」。
- どんでん返し：①無線は会社から入っていない。会社の無線を外から使える誰か ②1年前、ショウジはハルナをいつもと違う角で降ろした ③灰原はもう、娘のマユに近づいている
- 引き：黒いワゴンが横に並び、窓が下りる。男がかざしたスマホに、今この車の後ろの席のユキが映っている。

### 第3話 金曜日（1時20分）
- 出来事：ショウジはサンバイザーの裏からSDカードを出す。1年前の金曜0時41分のファイル。再生すると、後ろの席のハルナ「来週、引っ越すんです。つけてくる人がいて」。その時、運転席のショウジのスマホが鳴る。画面の名前は「灰原」。ショウジ「…はい。いつもの角で」。
- どんでん返し：①会社の映像は消えたが、ショウジはあの夜のカードを1年隠していた ②あの夜、ショウジのスマホにかけてきたのは灰原。ショウジは灰原を知っていた ③ショウジは言われたとおり、ハルナを角で降ろした。角に止まっていたのは、黒いワゴン
- 引き：ユキ「あなた、妹を、あの男に売ったの？」

### 第4話 買い手（1時50分）
- 出来事：ショウジの告白。2年前、マユの学費の借金。「浮気調査の探偵」を名乗る灰原が、車内カメラの映像を1本3万円で買った。客の乗った場所・降りた場所・電話の声。会社の車内カメラを外から見られるようにしたのは、配車センターの久保。無線の声は久保だった。ユキのスマホに電話。出たのは、ハルナ。
- どんでん返し：①ショウジは、客の車内カメラの映像を1本3万円で売っていた ②灰原に会社のカメラを見せていたのは、配車センターの久保。無線の声は久保 ③ハルナは生きていた。あの夜ワゴンから逃げ切って、身を隠していた。今夜はユキとハルナの計画
- 引き：マユから「お父さんの会社のタクシーが迎えに来てくれたよ。もう乗った」。久保が配車した7号車。運転席にいるのは灰原。

### 最終話 ドラレコ（夜明け）
- 出来事：ハルナが教えた久保のIDで、会社の車内カメラにつなぐ。7号車の後ろの席にマユ。運転席に灰原。ショウジは自分の車内カメラに向かって、全部を話す。「売ったのは、俺だ」。その映像を、会社の全部の車のモニターと警察に流す。灰原は7号車を止め、マユは逃げる。角で待っていたのは、ハルナ。夜明け、ショウジは自分で警察に行く。ドラレコの最後の映像は、ショウジ自身の顔。
- どんでん返し：①ショウジが見たのは、娘が乗る7号車の後ろの席。運転席は灰原 ②ショウジは自分の車内カメラで、自分が売ったことを全部話し、会社の全部の車と警察に流した ③マユを角で受け止めたのは、1年前にこの車を降りたハルナ
- 引き（次の作品も見たくなる終わり）：数日後、別の街の別のタクシー。若い女の客が運転手に聞く。「このドラレコ、誰が見てるんですか？」。運転手のスマホに「1本3万円」の通知。灰原の買い手は、ひとりではなかった。完。
