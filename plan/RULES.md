# もしもラボ 500本設計図 — 作成仕様（全担当共通）

## アカウント
- 名前：もしもラボ（Instagramリール、日本語、縦型、約60秒、3Dローポリのアニメ＋字幕、ナレーションなし、BGMあり）
- 型：もしも○○が消えたら／○○したらどうなる？ を、経過時間ごとに実データの数字で見せていく
- 第1作：日本中のコンビニが消えたら？（店舗56,054店→+1分 客が立ち尽くす→+1時間 ATM→+5時間 深夜の駆け込み→+1週間 スーパーに行列→+1か月 結果）

## 絶対ルール
1. フック（0〜2秒）：0フレーム目からお題の問いのテロップと、何かが起きる映像を出す。ロゴ紹介や前置きは禁止。1.5秒以内に異変（消える・止まる・数字が落ちるなど）を起こすか、カウントダウンを走らせる。
2. 着地の統一：最後の約10秒は必ず「結果」パートにする。どうなったかを、最終状態の映像と決め手の数字1つで見せる（例：結果 → 1年後、日本の人口は○万人減った）。オチは必ず「結果：〜」の一文で言い切る。投げっぱなしや「どうなるでしょう」で終わるのは禁止。消えた物が戻ってくる・元通りになる・明かりが戻る、のような結果をぼかす着地も禁止（ループ用の最後のカットも、結果の状態のまま冒頭に似せる）。
3. 最後の一言は必ず、見た人がひと言で答えられる質問にする（二択・数字・一番○○は？ など。コメントが付きやすい形）。まとめカードとキャプションにも同じ質問を出す。
   結果のあとに一言のひねりを入れてよい（例：でも実は、現実でも毎年○万人ずつ減っている）。ただし結果そのものは必ず出す。
4. 数字は必ず実在する公的統計・業界統計・論文をもとにする。不確かな数字は書かず、使うデータの種類と出典候補を書く。設計段階の数字には必ず（要確認）を付ける。
5. 避けるもの：実在の国が消える・戦争・特定の国や民族の対立、実在の人物（ネットミームの元になった人も含む）や企業のブランドの見た目、過度なグロ（縫合・出血の生々しい描写）、自殺・自傷、デマになりやすい災害予言。災害は公的な被害想定をもとに淡々と。
6. 1本の構成（約60秒）：0-2秒 フック／2-6秒 いつもの日常／6-48秒 経過時間（または規模）で4〜5段階エスカレート／48-58秒 結果／58-62秒 まとめカード（数字と出典）。最後のカットは冒頭と似た構図にしてループさせる。

## フックの型（hook_type に入れる記号）
- H1 カウントダウン：○○が消えるまで 0:03… が0秒目から走る
- H2 異変先出し：0秒目でいきなり消える／止まる／壊れる瞬間を見せてから時間を巻き戻す
- H3 衝撃数字：0秒目に巨大な数字（例：1日4,477万人）を叩きつける
- H4 あなた視点：あなたが今日から○○したら（POV、自分ごと）
- H5 ボタン・二択：押したら○○、押す？
- H6 スケール比較：○○を並べたら／集めたら、地球何周？

## 出力形式
JSON Lines（1行1本）。指定されたファイルパスに書き出す。各行は次のキー：
{"cat":"カテゴリ名","target":"主に刺さる層（例：20-40代 全般／30-40代 女性／10-20代 男性）","title":"冒頭テロップ兼タイトル（もしも〜？ の形、20字前後）","hook_type":"H1〜H6","hook":"0〜2秒で見せる映像とテロップ（具体的に1文）","beats":["+1分：…","+1時間：…","+1日：…","+1週間：…"],"result":"結果：…（どうなったかを言い切る一文。数字があれば入れる）","twist":"結果のあとの一言（任意、空でも可）","data":"使う数字と出典候補（要確認）","scenes":["…"],"mood":"…","keywords":"キャプションに入れる検索語3〜5個（スペース区切り）","virality":"S/A/B（伸びる見込み。リサーチで実績のある型ほど高く）"}

beats は経過時間か規模（1人→街→日本→世界）で4〜5個。各要素は40字以内。
同じ担当の中で似たお題を重複させない。タイトルの切り口は多様に（消えたら／止まったら／2倍になったら／全員が同時に／あなたが○○したら など）。

## リサーチで実績が確認できた強い型（参考）
- 体・睡眠・人体（寝ないとどうなる 448万〜727万回、血管を全部取り出すと 427万回、Zack D. Films の体ネタは1億回超え多数）
- 性別・人類・社会ルールが変わる（世界から男が消える 468万、スマホが消えたら 334万、ティッシュが月1箱 844万、消えるボタン 254万）
- 地球をいじる（自転停止 4600万、海が月に 6200万、ドーナツ型 5100万）、太陽・月・酸素が5秒消えたら（100万〜340万）
- 動物の絶滅（蚊 334万、ミツバチ）、時事のクマ
- 全人類が同時に○○（同時ジャンプ、一つのビルに住む）
- お金は具体的で俗っぽい設定ほど伸びる（1億円の使い方 1,310万）
- 日本の社会問題（少子化 出生67万人、外国人労働者257万人、物価、二季、古古古米、残業キャンセル界隈）はまだ空いている領域

## 着地は人への影響で言い切る（2026/10/20 ゆうとの指摘・最重要）
- 結果は「何がいくつ消えた」で終わらせない。それで人間の暮らし・お金・体・心がどう変わったかを数字で言い切る（例：蚊の回＝マラリアだけで年61万人が助かる）。
- 流れは 何が起きた → 人数・世帯 → お金 → 体や心や生活 → 結果（人への影響）。途中の数字も全部この結論につながる順に並べる。
- 見た人が納得して、だれかに教えたくなる一文になっているかを毎回チェック。数だけ・比較だけで終わる台本は作り直し。
- 推計や単純計算で言い切るときは、画面のチップとキャプションに（推計）（単純計算）と条件を書く。
- 最後の質問も、結論とつながる問いにする（関係のない好き嫌いの二択にしない）。
- 字幕の時間：結果 48.1〜53.8、ひねり 53.9〜56.1、質問 56.2〜59.4（結果の一文はナレーションが間を取って長くなるので約5.7秒取る）。ひねりは短く（15字以内）。
- 場面の効果音は META.sfx = [[秒, 種類, 値]] で入れる。種類：poof（消える）、whoosh、meter（値0〜1、高いほど長く不穏）、alarm、bubble、buzz、caw、skitter、drone。数字の強調は今まで通り META.impacts。
- 長さは60秒に縛らなくていい企画もある（候補を並べて比べる回など）。その場合も結果・ひねり・質問の字幕の並びは同じ。
