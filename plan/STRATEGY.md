## 4. 昇格・降格（数字で決める）

72時間たった時点の再生で判断する。中央値は直近20本の、その媒体の72時間再生の中央値。

- 挑戦→柱候補：インスタか TikTok で中央値の2倍以上。すぐに同じ型の派生を3本作って在庫の前に入れる。
- 柱候補→柱：派生3本のうち2本以上が中央値以上なら、名前をつけて柱シリーズに入れる（このファイルの表に足す）。
- 柱の見直し：そのシリーズの直近5本の中央値が、インスタ・TikTok の両方で全体中央値の0.7倍を下回ったら、柱から外して週1本の扱いに下げる。
- 同じお題の続編（例：蚊の別視点）は、元の回が中央値の5倍以上のときだけ作る。

## 5. 伸びなかった回は残す（2026/11/02 に方針を変更）

結論：消さない・隠さない（インスタのアーカイブ、TikTok の 自分のみ もしない）。

根拠：
- TikTok 公式：フォロワー数も、過去に伸びた動画があるかどうかも、おすすめの直接の要素ではない（Newsroom「How TikTok recommends videos #ForYou」）。コケた回を消しても次の回の伸びは変わらない。
- TikTok ではコケた回も報酬を生む（ハエ 3,800再生で363円、クラミジア 4,300再生で318円）。自分のみ にするとそれが止まる。
- インスタの責任者モッセーリ：伸びなかった投稿を残しても実質デメリットはない。YouTube の Todd Beaupre：消すとその動画を見た視聴者とのつながりが切れるので、強い理由がなければ消さない。
- 同じ動画を3媒体に出しているので、1つの媒体の数字で消すと別の媒体の当たりを殺す（北朝鮮はインスタ6,150・TikTok 13.6万、4時間睡眠はインスタ21.8万・TikTok 4,700）。
- 1日4本なので、コケた回も2〜3日でプロフィールの上3段（9本）から落ちる。

見え方の整え方：
- ピン留め：各媒体で今の路線の当たりを3本固定する（TikTok は TikTok 予約担当が TikTok Studio かプロフィールで、インスタはゆうとがアプリで）。
- 挑戦枠の回は META.trial: true にする。投稿サーバーがインスタのお試しリール（trial_params・graduation_strategy SS_PERFORMANCE）で出し、フォロワー以外にまず見せて、数字がよければインスタが自動で一覧に出す。コケた回は一覧に載らない。TikTok・YouTube はふつうに出す。
- 例外：実在の人やネタに問題があった回（0034 など）は、日数に関係なく削除してよい。

## 8. TikTok基準の作り（2026/10/28〜・最優先）

### 分かったこと（TikTok Studio の数字）
- TikTok の1日の再生：10/21 約43万 → 10/23 19.9万 → 10/26 9.6万。当たり（蚊・ジャンプ・ゴキブリ）はすべて10/19〜20にアップした最初の10本。10/22以降の約25本で1万を超えたのは腕立て（4.3万）だけ。
- 同じ動画がインスタでは当たっている（腕立て 18.6万・ハエ 8.5万・4時間睡眠 8.4万）。中身ではなく、TikTok での見られ方の問題。
- TikTok では全動画で 0:01〜0:02 に一番離脱。平均視聴は16〜19秒（64秒の動画）、最後まで見る人は2〜5%。数字で勝っていたのは蚊（平均24秒・完走11%）だけ。2分のランキングは平均38秒。
- シェア率が高い回（腕立て 0.56%）は伸びた。

### ルール
- 動画は TikTok 基準で作り、インスタ・YouTube も同じ動画を出す（docs/PRODUCTION.md の v2 構成）。0秒目＝サムネイル、0.6秒で異変、0秒からナレーション、いつもの日常は先に見せない、10〜12秒ごとに次を見たくなる一言、61〜65秒。
- サムネイル（0秒目）は全媒体共通。一覧（縦3:4に切り抜かれる）でも切れない位置にタイトルとシリーズのバッジ、その下に主役。シリーズごとに絵の型をそろえて、一覧に並んだときにひと目でシリーズと内容が分かるようにする。
- TikTok の投稿は1日4本まで、3時間以上あける（まとめて何本も出さない。2026/11/03〜。それまでは3本・4時間）。TikTok で当たっている型（社会の消えたら を最優先、次に人体の限界）を先に出す。
- いつわ劇場（ドラマ）はもしもラボのアカウントには出さない。
- TikTok の数字は TikTok Studio の動画ごとの数字（再生・平均視聴・完走率・シェア）で見る。公開ページの数字は一部の動画しか取れない。


## カバー（表紙）の柱の色（2026/11/03 決定）
カバーの文字は動画タイトルそのもの（もしも〇〇たら？）を白と黄色・黒の縁取りで入れる。上の札は柱の名前にして、色だけ柱で分ける：図星＝赤（2026/11/03〜図星は 沼が消えたら＝赤・男と女のもしも＝ピンク・大人の本音＝茶 に分ける。これからの回の series もこの3つのどれかにする）、人体の限界＝青、絶滅ボタン＝緑、お財布のもしも＝金、社会の消えたら＝マゼンタ、全員で同時に＝橙、ヤバい順＝紫、それ以外＝ミント（札の文字は もしもラボ）。カバーは 1080×1920 で、TikTok の予約のときにカバーをアップロードで付ける。
